Backup automático

Backup ainda não configurado. Sem ele, se o iPhone apagar os dados do navegador, a tabela é perdida.
Como configurar (passo a passo, uma vez só)
  1. Crie uma conta grátis em github.com (se ainda não tiver). Anote o nome de usuário.
  2. Toque no + no topo → New repository. Nome: honorarios-dados. Marque Private (muito importante). Toque em Create repository.
  3. Abra github.com/settings/personal-access-tokens/new (Settings → Developer settings → Fine-grained tokens → Generate new token).
  4. Token name: app honorarios. Expiration: escolha a mais longa (ou "No expiration").
  5. Em Repository access escolha Only select repositories e selecione honorarios-dados.
  6. Em Permissions → Repository permissions → Contents escolha Read and write. Não precisa de mais nada.
  7. Toque em Generate token e copie o código (começa com github_pat_).
  8. Cole aqui junto com o usuário e o nome do repositório e toque em Conectar.
  9. Guarde o token no app Senhas ou nas Notas do iPhone. Se um dia os dados do app sumirem, é só colar de novo e tudo volta.
O token só dá acesso a esse repositório. Ele fica salvo apenas neste iPhone.

Instalar no iPhone

  1. Abra este endereço no Safari (precisa ser o Safari).
  2. Toque em Compartilhar (quadrado com seta para cima).
  3. Role e toque em Adicionar à Tela de Início → Adicionar.
  4. Use sempre pelo ícone Honorários da tela inicial.
